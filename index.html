El secreto de la computadora

Una aventura en cuatro escenas donde una estudiante descubre que la tecnología puede conectar mundos.

¿Cómo leerla? Recorre las cuatro escenas en orden. Después prueba la experiencia de realidad aumentada: permite el acceso a la cámara y apunta a una de las ilustraciones impresas o mostradas en otra pantalla. Para activar el reconocimiento visual, primero hay que cargar el archivo de marcadores comic.mind generado a partir de estas cuatro imágenes.

1. El hallazgo

Vanessa encuentra una computadora antigua en el laboratorio. Al encenderla, descubre que la pantalla tiene un brillo extraño.

2. El mensaje

En la pantalla aparece un mensaje: “Hola… ¿me ayudas?”. Vanessa decide averiguar quién está intentando comunicarse.

3. El visitante

Un pequeño robot holográfico sale de un portal digital. Necesita ayuda para volver al mundo del que proviene.

4. Un nuevo amigo

Vanessa estabiliza el portal y el robot puede regresar a casa. Antes de irse, le agradece por demostrar que la tecnología también puede crear amistades.

✨ Prueba la realidad aumentada

Esta experiencia utiliza la cámara del dispositivo para reconocer las ilustraciones y mostrar contenido digital encima de ellas. Para que el reconocimiento funcione, debes crear el archivo comic.mind con las cuatro imágenes usando el compilador de MindAR y subirlo junto a index.html.

Estado: cámara apagada. Primero configura el archivo comic.mind siguiendo el README.
Nota: la cámara requiere permiso del usuario y una conexión HTTPS, como la que ofrece GitHub Pages.
